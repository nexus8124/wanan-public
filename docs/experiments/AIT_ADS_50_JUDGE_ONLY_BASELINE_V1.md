混淆矩阵口径为 `TP=21, FP=2, FN=4, TN=15`。其中 `FN=4` 包含 3 条明确漏判和 1 条真阳待查；8 条假阳待查不计为 TN，因此总体正确数为 36，`36/50=72%`。

## 基线结论

模型对真阳具有较高精确率和召回率，但对假阳较保守：25 条假阳中有 8 条进入待查。当前主要短板是覆盖率和假阳类别 F1，而不是大量方向性误判。

本结果使用 AIT-ADS 攻击时间窗弱标签，适合用作工程对比基线，不应表述为事件级真实准确率。后续实验必须使用相同的 50 条确定性子集、模型、Temperature、Prompt 和指标口径，仅改变被测变量。

## 第二阶段对比要求

第二阶段完整 ReAct 必须在相同 50 条样本上运行，并与本基线对比：

- Accuracy、Macro-F1、Coverage 和待查率；
- 明确误报、明确漏报和两类待查；
- LLM 调用次数、Token/样本和平均延迟；
- 工具成功率、无证据率、超时率和失败重试次数；
- 每个最终结论是否能引用实际工具证据。

只有当 ReAct 的准确性或覆盖率增益能够抵消其 Token 和延迟成本时，才视为有效优化。
